Resumo do Projeto

Este projeto analisa dados biometricos de olhos Barrett II para identificar grupos naturais (clusters) usando diferentes algoritmos de clustering.

Features biometricas:

  • AL: Axial Length (comprimento axial do globo ocular)
  • ACD: Anterior Chamber Depth (profundidade da camera anterior)
  • WTW: White-to-White (distancia branco-a-branco)
  • K1, K2: Keratometry (curvatura corneana em dois eixos)
