01

Introdução

Contexto do problema e objetivos da análise

Contexto de Negócio

O serviço de Knowledge Engineering oferece análise especializada de dados biométricos para aplicações oftalmológicas. Neste projeto, temos como objetivo identificar perfis oculares baseados em medidas biométricas da córnea e do segmento anterior do olho.

A identificação de grupos naturais nos dados biométricos permite:

  • Classificação automática de pacientes em perfis clínicos distintos
  • Suporte à decisão cirúrgica para procedimentos refrativos e de cataracts
  • Personalização de lentes intraoculares (LIOs) baseadas no perfil biométrico
  • Identificação de casos atípicos que requerem atenção especial
Nota Importante
A coluna "Correto" contém a classificação original e não será utilizada para o processo de clustering. Esta informação serve apenas como descrição complementar para interpretação dos perfis identificados posteriormente.

As 5 Variáveis Biométricas

Utilizamos cinco medidas biométricas do olho que são fundamentais para caracterização do perfil corneano:

AL
Axial Length (Comprimento Axial)
Distância entre a córnea e a retina, medida em milímetros. Indica o tamanho total do olho e é crucial para cálculo de lentes intraoculares.
ACD
Anterior Chamber Depth (Profundidade de Câmara Anterior)
Distância entre a córnea e o cristalino. Influencia a profundidade da câmara anterior e é importante para cirurgia de cataracts.
WTW
White-to-White Distance (Distância Branco a Branco)
Medida horizontal da córnea, de uma borda escleral a outra. Utilizada para dimensionamento de implantes e lentes de contato.
K1
Curvatura do Meridiano Menos Curvo
Representa a curvatura da córnea no meridiano mais plano. Medida em dioptrias (D) ou milímetros de raio. Primeiro valor de ceratometria.
K2
Curvatura do Meridiano Mais Curvo
Representa a curvatura da córnea no meridiano mais íngreme. Medida em dioptrias (D) ou milímetros de raio. Segundo valor de ceratometria.
Referência Anatômica
Para uma explicação detalhada sobre a anatomia do olho e as medições biométricas, consulte a documentação técnica disponível em: NCBI - Ocular Biometry

Análise Exploratória de Dados (EDA)

Exploração inicial para entender a distribuição e características

O que é EDA e Por que Fazer

A Análise Exploratória de Dados (EDA) é uma abordagem inicial que nos permite compreender a estrutura dos dados antes de aplicar algoritmos de machine learning. Para clustering, esta etapa é fundamental para:

  • Identificar padrões e distribuições nas variáveis biométricas
  • Detectar valores atípicos (outliers) que podem influenciar os resultados
  • Compreender correlações entre variáveis
  • Validar suposições sobre a natureza dos dados
  • Guiar decisões sobre pré-processamento adequado

Medidas Estatísticas

Calcularemos as seguintes estatísticas descritivas para cada variável:

Tendência Central
  • Média (Mean): Valor médio dos dados
  • Mediana (Median): Valor central
Dispersão
  • Desvio Padrão (Std): Variabilidade dos dados
  • Variância: Quadrado do desvio padrão
Extremos
  • Mínimo/Máximo: Valores de fronteira
  • Amplitude: Diferença entre max e min
Distribuição
  • Quartis (25%, 50%, 75%): Divisões da distribuição
  • Assimetria/Icrtose: Forma da distribuição

Visualizações que Criaremos

Serão gerados os seguintes gráficos para análise visual:

Histogramas
Distribuição de cada variável individualmente. Identifica multimodalidade.
Boxplots
Visualização de outliers e comparação entre variáveis.
Correlation Heatmap
Mapa de correlação entre todas as variáveis biométricas.
Pairplot
Scatter plots entre pares de variáveis. Revela relações e clusters naturais.
Time Series (se aplicável)
Evolução temporal dos dados, se houver ordem temporal.

O que Buscamos na EDA

  • Multimodalidade: Indicação de grupos naturais nos dados
  • Outliers: Valores extremos que podem ser erros ou casos especiais
  • Correlacões: Variáveis que variam juntas (ex: K1 e K2)
  • Escala: Diferenças significativas entre ranges das variáveis
  • Valores faltantes: Necessidade de imputação

Pré-processamento de Dados

Normalização e preparação para algoritmos de clustering

Por que Pré-processamento é Crítico

Algoritmos de clustering são extremamente sensíveis à escala das variáveis. Quando variáveis têm escalas diferentes, aquelas com valores maiores dominam o cálculo de distâncias, ignorando variáveis potencialmente mais importantes.

Exemplo Prático
AL (20-30 mm) tem valores muito maiores que K1 (38-48 D). Sem normalização, a distância euclidiana seria dominada pelo AL, e K1 seria quase ignorado.

Métodos de Normalização

StandardScaler (Z-Score)

O que faz: Transforma os dados para média 0 e desvio padrão 1.

Fórmula: z = (x - μ) / σ

Quando usar: Quando os dados seguem distribuição normal ou quando queremos identificar outliers.

MinMaxScaler (0-1)

O que faz: Escalona os dados para o intervalo [0, 1].

Fórmula: x_norm = (x - min) / (max - min)

Quando usar: Quando conhecemos os limites dos dados e queremos preservar a forma da distribuição.

# StandardScaler - Z-Score Normalization
from sklearn.preprocessing import StandardScaler

scaler_standard = StandardScaler()
X_standard = scaler_standard.fit_transform(X)

# MinMaxScaler - 0 to 1 Normalization
from sklearn.preprocessing import MinMaxScaler

scaler_minmax = MinMaxScaler()
X_minmax = scaler_minmax.fit_transform(X)

# Comparação: dados originais vs normalizados
print(f"Original: mean={X.mean():.2f}, std={X.std():.2f}")
print(f"Standard: mean={X_standard.mean():.2f}, std={X_standard.std():.2f}")
print(f"MinMax: mean={X_minmax.mean():.2f}, std={X_minmax.std():.2f}")

05

Definição do Número de Clusters (K)

Métodos para determinar o número ótimo de grupos

O Desafio

Em problemas reais de clustering, não sabemos quantos grupos existem nos dados. Diferente da classificação supervisionada, onde temos labels, no clustering não supervisionado precisamos descobrir a estrutura.

Faixa de Teste
Testaremos valores de K de 2 a 15 para cada método. Este range cobre desde grupos binários até segmentações mais granulares.

Métodos para Encontrar K Ótimo

Elbow Method (Cotovelo)
Plota a inércia (soma das distâncias quadráticas) vs K. O "cotovelo" indica K ótimo onde a adição de mais clusters não reduz significativamente a inércia.
Silhouette Score
Mede quão similar um ponto é ao seu próprio cluster comparado a outros clusters. Varia de -1 a 1. Valores mais altos indicam melhor separação.
Gap Statistic
Compara a dispersão intra-cluster com a esperada sob uma distribuição nula (uniforme). O K que maximiza o gap é selecionado.

Visualizações que Geraremos

Método Gráfico O que Procurar
Elbow Method Line plot: K vs Inércia Ponto de "cotovelo" onde a curva dobra
Silhouette Score Line plot: K vs Silhouette Pico mais alto (mais próximo de 1)
Gap Statistic Line plot: K vs Gap Primeiro K onde Gap(K) ≥ Gap(K+1) - s(K+1) 
# Métricas para determinar K ótimo
from sklearn.metrics import silhouette_score
from sklearn.cluster import KMeans

# Testando K de 2 a 15
k_range = range(2, 16)
silhouette_scores = []
inertias = []

for k in k_range:
    kmeans = KMeans(n_clusters=k, random_state=42, n_init=10)
    labels = kmeans.fit_predict(X)
    silhouette_scores.append(silhouette_score(X, labels))
    inertias.append(kmeans.inertia_)

# Identificar melhor K baseado em silhouette
best_k = k_range[np.argmax(silhouette_scores)]
print(f"Melhor K pelo Silhouette Score: {best_k}")
06

K-Means Clustering

Algoritmo de partição mais utilizado

Como o K-Means Funciona

K-Means é um algoritmo de partição que divide os dados em K grupos disjuntos. É computacionalmente eficiente e amplamente utilizado.

1
Inicialização
K centroides são inicializados (por padrão, usando k-means++ que distribui os centros de forma inteligente).
2
Atribuição de Clusters
Cada ponto é atribuído ao cluster cujo centróide está mais próximo (distância euclidiana).
3
Atualização
Os centroides são recalculados como a média de todos os pontos atribuídos ao cluster.
4
Iteração
Os passos 2 e 3 se repetem até que os centroides não mudem significativamente ou o número máximo de iterações seja atingido.

Parâmetros Principais

Parâmetro Valor Recomendado Descrição
n_clusters Definido via Elbow/Silhouette Número de clusters
init 'k-means++' (padrão) Método de inicialização inteligente
n_init 10 Número de inicializações independentes
random_state 42 Reprodutibilidade
max_iter 300 Máximo de iterações por execução 
# K-Means Clustering
from sklearn.cluster import KMeans

# Criar e treinar modelo
kmeans = KMeans(
    n_clusters=5,
    init='k-means++',
    n_init=10,
    random_state=42,
    max_iter=300
)

# Ajustar e predizer
cluster_labels = kmeans.fit_predict(X_normalized)
centroids = kmeans.cluster_centers_

# Métricas de validação
from sklearn.metrics import silhouette_score, calinski_harabasz_score

sil = silhouette_score(X_normalized, cluster_labels)
ch = calinski_harabasz_score(X_normalized, cluster_labels)
inertia = kmeans.inertia_

print(f"Silhouette Score: {sil:.4f}")
print(f"Calinski-Harabasz Index: {ch:.4f}")
print(f"Inertia: {inertia:.4f}")

DBSCAN Clustering

Algoritmo baseado em densidade com detecção de ruído

Diferença Fundamental do K-Means

DBSCAN (Density-Based Spatial Clustering of Applications with Noise) é fundamentalmente diferente do K-Means porque:

  • Não requer especificar K antecipadamente
  • Identifica outliers automaticamente (pontos com label -1)
  • Encontra clusters de forma arbitrária (não esféricos)
  • Baseia-se em densidade em vez de centroides

Conceitos-Chave

Parâmetro Descrição Como Determinar
eps (ε) Raio da vizinhança ao redor de um ponto Método do k-distância (gráfico)
min_samples Número mínimo de pontos para formar um cluster Tipicamente 5-10 × dim. dos dados

Como Determinar eps

Utilizaremos o método do k-distância: para cada ponto, calcula-se a distância ao k-ésimo vizinho mais próximo. O gráfico resultante mostra as distâncias em ordem decrescente. O "cotovelo" indica um bom valor de eps. 

# Encontrar eps usando k-distance graph
from sklearn.neighbors import NearestNeighbors
import numpy as np

k = 5  # min_samples - 1
neigh = NearestNeighbors(n_neighbors=k)
neigh.fit(X_normalized)
distances, indices = neigh.kneighbors(X_normalized)

# Distância ao k-ésimo vizinho
k_distances = distances[:, k-1]
k_distances = np.sort(k_distances)[::-1]

# Plotar e identificar "cotovelo"
import matplotlib.pyplot as plt
plt.figure(figsize=(10, 6))
plt.plot(range(len(k_distances)), k_distances)
plt.xlabel('Pontos (ordenados)')
plt.ylabel(f'Distância ao {k}º vizinho')
plt.title('Método do K-Distância para encontrar eps')
plt.grid(True)
plt.savefig('k_distance_plot.png')

Grid Search

Testaremos diferentes combinações de eps e min_samples para encontrar a melhor configuração: 

# DBSCAN com grid search
from sklearn.cluster import DBSCAN
from sklearn.metrics import silhouette_score

eps_range = np.arange(0.3, 1.5, 0.1)
min_samples_range = range(5, 15)

best_score = -1
best_params = {}

for eps in eps_range:
    for min_samples in min_samples_range:
        dbscan = DBSCAN(eps=eps, min_samples=min_samples)
        labels = dbscan.fit_predict(X_normalized)
        
        # Ignorar configurações com apenas 1 cluster ou muito ruído
        n_clusters = len(set(labels)) - (1 if -1 in labels else 0)
        noise_ratio = list(labels).count(-1) / len(labels)
        
        if n_clusters >= 2 and noise_ratio < 0.5:
            score = silhouette_score(X_normalized, labels)
            if score > best_score:
                best_score = score
                best_params = {'eps': eps, 'min_samples': min_samples}

print(f"Melhores parâmetros: {best_params}")
print(f"Melhor Silhouette: {best_score:.4f}")

Clustering Hierárquico

Abordagem agglomerativa com dendrogramas

Aglomeração Bottom-Up

O clustering hierárquico agglomerativo começa com cada ponto como seu próprio cluster e progressivamente une os clusters mais próximos até形成一个 único cluster (ou até K clusters).

1
Início
Cada ponto é um cluster individual (N clusters para N pontos).
2
Cálculo
Calcula-se a distância entre todos os pares de clusters.
3
União
Os dois clusters mais próximos são unidos em um novo cluster.
4
Repetição
Repete até restar apenas K clusters ou 1 cluster.

Métodos de Ligação

Método Descrição Quando Usar
Ward Minimiza a variância within-cluster Clusters esféricos, bom para K-Means-like
Complete Distância máxima entre pontos dos clusters Clusters compactos, detecta outliers
Average Média das distâncias entre todos os pares Robusto a ruído
Single Distância mínima entre pontos Clusters alongados, mas sujeito a chaining 
# Agglomerative Hierarchical Clustering
from sklearn.cluster import AgglomerativeClustering
from scipy.cluster.hierarchy import dendrogram, linkage, cophenet
from scipy.spatial.distance import pdist

# Testando diferentes linkages
linkage_methods = ['ward', 'complete', 'average', 'single']

for method in linkage_methods:
    # Clustering com K definido (baseado em análise prévia)
    hc = AgglomerativeClustering(n_clusters=5, linkage=method)
    labels = hc.fit_predict(X_normalized)
    
    # Cophenetic correlation (qualidade do dendrograma)
    Z = linkage(X_normalized, method=method)
    c, coph_dists = cophenet(Z, pdist(X_normalized))
    
    print(f"{method}: Silhouette={silhouette_score(X_normalized, labels):.4f}, Cophenetic={c:.4f}")

Dendrograma

O dendrograma é uma representação gráfica da hierarquia de clusters. A altura das linhas indica a distância na qual os clusters foram unidos.

Validação e Interpretação dos Clusters

Métricas e análise de perfis identificados

Como Validar Clusters

A validação de clustering é multifacetada. Utilizamos métricas quantitativas combinadas com análise qualitativa dos perfis.

Métricas de Validação

Métrica Range Interpretação
Silhouette Score [-1, 1] > 0.5: bom, > 0.7: excelente
Calinski-Harabasz [0, ∞) Quanto maior, melhor separação
Davies-Bouldin [0, ∞) Quanto menor, melhor (< 1 é bom) 
# Validação completa
from sklearn.metrics import (
    silhouette_score,
    calinski_harabasz_score,
    davies_bouldin_score
)

def evaluate_clustering(X, labels, method_name):
    n_clusters = len(set(labels)) - (1 if -1 in labels else 0)
    
    if n_clusters < 2:
        return "Menos de 2 clusters"
    
    sil = silhouette_score(X, labels)
    ch = calinski_harabasz_score(X, labels)
    db = davies_bouldin_score(X, labels)
    
    return {
        'method': method_name,
        'n_clusters': n_clusters,
        'silhouette': sil,
        'calinski_harabasz': ch,
        'davies_bouldin': db
    }

A coluna "Correto" não será usada para clustering, mas可以用来验证我们的分组是否与临床分类一致: 

# Análise cruzada (uso informativo, não para clustering)
import pandas as pd

# Tabela de crosstab: clusters vs classificação original
df_analysis = pd.DataFrame({
    'cluster': labels,
    'correto': df['Correto']
})

crosstab = pd.crosstab(df_analysis['cluster'], df_analysis['correto'])
print(crosstab)

# Pureza do cluster: quanto cada cluster é "puro"
def cluster_purity(labels, true_labels):
    contingency = pd.crosstab(labels, true_labels)
    purity = contingency.max(axis=1).sum() / len(labels)
    return purity

print(f"Pureza: {cluster_purity(labels, df['Correto']):.4f}")
